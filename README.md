# AI Chatbot Web Application

## Overview
The AI Chatbot Web Application is a simple web-based chatbot developed using Python, Flask, HTML, CSS, and JSON. The chatbot interacts with users through a web interface and provides automated responses based on predefined keywords and responses.

## Features

* Interactive Chat Interface
* AI-Based Response Generation
* Flask Backend Integration
* Dynamic Chat Display
* Multiple User Query Handling
* Responsive User Interface

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JSON

## How to Run the Project

1. Install Flask:
   py -m pip install flask
2. Run the application:
   py app.py
3. Open your browser and visit:
   http://127.0.0.1:5000
